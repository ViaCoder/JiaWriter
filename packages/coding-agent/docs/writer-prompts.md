# 提示词分阶段说明

JiaWriter 发给模型的规则都在 `src/writer/prompts/`，到了哪一步才发哪一段，每段只发一次，压缩后补发。输入 `/jw prompts` 可以看到下表和本会话已经发过哪些。

| 阶段 | 什么时候发 | 发什么 | 怎么发 |
|---|---|---|---|
| 常驻 | 每次请求 | 身份、`PROMPT_ADD`、核心规则、skill 索引、工具说明 | 系统提示和工具说明 |
| 日期 | 第一条用户消息，以及日期变化后的第一条 | `[Date: …]` | 消息开头 |
| 开始写作 | `topic_open`、已有主题的新一轮，或直接 `write`、`edit` | 写作手册 | 工具结果或消息 |
| 确定文体 | 模型读 skill | 该文体的要求 | `read` |
| 检索 | 第一次 `web_search`、`web_fetch` 成功 | 检索手册 | 工具结果 |
| 某种方式 | 该方式第一次成功 | 该方式的规则，搜索 4 种、抓取 5 种 | 工具结果 |
| 记素材 | 第一次 `material_add` | 素材规则 | 工具结果 |
| 检查 | 各检查工具第一次 | 该工具结果的处理方法 | 工具结果 |
| 导出 | 第一次 `export_document` | 导出报告的处理方法 | 工具结果 |
| 回退 | 第一次 `draft_restore` | 回退步骤 | 工具结果 |
| 压缩 | 用量到上下文窗口的 80% | 只总结文件里没有的内容 | 摘要请求 |
| 压缩后 | 压缩之后 | 写作状态、写作手册 | 摘要和消息 |
| 上游内部 | `claude`、`codex` 方式 | 搜索和读取指令 | 内部请求 |

压缩时，主题文件夹就是记忆：稿件路径和字数、素材数量、文体、用户的原话都由程序从磁盘写入摘要，模型只补充已确认的决定、用户偏好和下一步。模型摘要失败时这些内容照样保留。
