# 写作视角与认知框架

真实公文 226 篇的站位、引用、数据、归因和分寸。写上行文（调研报告、请示、建议）时读。

## 站位

- 开篇多从国家战略或全局定位切入（过半），其次是政策依据或受命说明（约两成）；面向群众的讲话才从一线场景切入。
- 制度缺陷几乎从不作为切入点（226 篇中 2 篇）：要批评体制，先写战略高度和已有成效。
- 站位高低看行文方向、授权来源、本机关层级和读者身份，基层单位不替上级定调。

## 引用

- 权威引用的顺序：总书记 → 党中央 → 国务院 → 省委或部党组 → 法律 → 本单位领导 → 专家，顺序不倒过来。
- 只引参考资料里有原文的论述，写明出处；引本单位领导要写姓名、职务和原话，用来交代授权。
- 引用多少按论证需要定；讲本单位做法的经验材料不必借权威背书。

## 数据

- 数据集中在前半篇的基本情况和成效部分，建议部分几乎不用数据。
- 好用的四种句式：落差对照（支持率九成以上、参与率不到一半）；绝对数、相对数、比率三件套；城乡或内外对比；把宏观数据折算到个人体感（一个三口之家一年产生约 1 吨垃圾）。
- 调研的时间、地点、样本、方式，只在材料里有时才写，不虚构走访和座谈。

## 案例

- 正面经验写全名称、地点、项目和金额，便于别人照做。
- 已公开处理的负面典型，按公开报道写，职务前加“原”。
- 材料里匿名的人和单位保持匿名；批评同级或上级用“一些地方”“有的部门”。

## 归因

- 成绩写成“在……领导下”“在……支持下”，不归功于本单位。
- 问题分两种归法：客观原因归给历史、地理、发展阶段和外部环境，不追责任；主观原因归给思想作风，并加“个别”“部分”“少数”限定。

## 力度

- “建议”只用于上行文；有权决定的单位不说“建议”。
- 面向不能命令的对象用“希望”；面向本系统用“要”“切实”。
- “严禁”“不得”只用于工作意见这类规范性文件。
- 建议要落到“由哪个部门做什么”；最弱的建议只请求启动研究，不越权承诺。

## 敏感问题

- 部门之间有分歧时，双方都写明，归因于工作分歧，不作指控。
- 把具体批评写成通例（“改革涉及部门利益时，往往……”）。
- 最重的判断借用公开报道或他人的话说出。
- 先写本单位的责任，再向下提要求。

## 收尾

- 上行的调研报告收在最后一条建议上，不加“特此报告”，谦辞在开头说一次。
- 工作意见末条多写督查问责或反馈渠道。
- 经验材料说“取得初步成效”，不宣称已经完成。

## 不做

- 不用“高度重视”之类的表态开篇，不用“狠抓落实”之类的空动词充数。
- 问题段不能只有四字排比，要有案例或数字。
- 经验材料不写转折，不写本单位尚未解决的问题。
