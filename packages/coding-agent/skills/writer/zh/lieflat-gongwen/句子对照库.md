# 句子对照库

同一个意思的短句写法和公文写法放在一起，看长度和顿号是怎么挂上去的。自检报告出现句长、顿号或要求词偏离时读。

## 先判偏哪一侧

- 调研报告、领导讲话、经验材料、经验总结、法定报告：容易并列不足，要补。
- 工作意见、工作方案：容易并列过度，要砍。

## 并列不足：四种补法

一句话里常同时用两三种。补的是信息，不是修辞；为凑字数另加一段只会把文章写水。

1. 事项并列：把“这件事”换成“这几件事”。
   - 短：要由市工业和信息化局牵头选题，选工序清晰的环节。
   - 长：要由市工业和信息化局牵头，会同行业协会到车间里选题，把外观检测、排产调度、设备预测性维护、能耗优化这一类工序清晰、判定标准明确、数据可采的环节列出来，逐个明确改造前后的可测指标。
2. 主体或责任并列：把“分到基层”换成“镇干部包村、村干部包组、党员包户”。
3. 条件并列：把“把要求写清楚”换成“把调取范围、使用用途、留存期限、销毁方式和责任人逐项写进备忘录”。
4. 收口：句末挂一句效果或底线，如“确保设施状况随时说得清”“一天都不能含糊”。

再举两例：

- 短：当前技术服务商按项目报价收款，风险都在企业一侧。
- 长：当前技术服务商普遍按项目额报价、按节点收款、按验收单结项，效果好坏、达标与否、能否长期运行，风险全部落在企业一侧，企业自然把决策一推再推。
- 短：要坚持一户一策，把该办的环节一次交清，不许空转。
- 长：要坚持一户一策，把宅基地选址、图纸审查、施工队伍、竣工验收这四个环节一次交清，不许再出现边等方案、边等资金、边等工队的空转。

要求词偏少时，不是漏写了“要”，是没写出动作：先把动作写具体，“要”才有地方挂。经验总结讲已经做完的事，要求词多来自句末的“确保”，不是“要”。

## 并列过度：砍法

- 一处并列保留最能界定范围的三项，其余并入后文或删掉。
  - 过度：岗位设置要从社区实际工作量、人口结构、服务半径、财政承受能力、历史沿革、居民诉求出发。
  - 适度：岗位设置要从社区实际工作量、人口结构、服务半径出发。
- 用分句代替顿号：“同步配置照明和监控，并按标准配齐灭火器材”比五项顿号并列更清楚，句子反而更长。
- 强制词超额时这样换，语气不弱：
  - “不得下派”改为“一律取消”
  - “不得随意抽调”改为“不能随意抽调”
  - “不得违规使用”改为“违规使用的，要一并纠正”

## 不该堆的地方

- 引语：企业主、群众的原话本来就短，不改。
- 场面：靠短句和白描，堆了并列就没了画面。
- 规范性文件的约束条款：每条本身就是要求，不再加并列。
- 原来就短的句子，如果是一句原话、一个场面或一句反问，留着。
