# 报告分析

## 动笔之前

- 确认报告的读者（领导、主管部门、内部团队）、用途和篇幅。
- 导入全部参考资料，列出要回答的问题，逐个在资料和检索结果中找依据。

## 结构

- 标题写明对象和主题，例如“关于××情况的调研报告”。
- 一级标题用“一、二、三、”，二级标题用“（一）（二）”，三级标题用“1．2．”。
- 常用结构：基本情况、主要问题、原因分析、对策建议。每条问题都有对应的建议。
- 每部分先写结论句，再写数据和事例。

## 内容

- 数据写明口径、时间和来源，例如“据市统计局2026年9月发布的数据”。
- 问题写具体表现和影响范围，原因写到可以采取措施的层面。
- 建议写清做什么、谁来做、何时完成，能量化的写出目标值。
- 案例只取自参考资料或检索结果，正文写明日期和来源。

## 文风

- 用平实、准确的书面语，句子完整，一句一事。
- 少用形容词和副词，用数据和事实说明程度。
- 规范性要求使用“应当”“须”；禁止性规定使用“不得”“严禁”。

## 收尾检查

- 运行 style_check（词表 core-zh 与 gongwen-zh），改写标出的句子后再检查一次。
- 用 export_document 导出 docx，默认排版方案 default-zh。
