# 报告分析

写企业和研究类的报告、分析和总结：先结论后依据，问题和建议一一对应。

## 动笔之前

- 导入全部参考资料，列出要回答的问题，逐个在资料中找依据；用户要求检索时才用检索结果补充。

## 结构

- 标题写明对象和主题，例如“关于××情况的调研报告”。
- 一级标题用“一、”，二级标题用“（一）”，一般只用两级。
- 开头一段先写结论和建议要点，正文写依据，末尾不另写结论。
- 常用结构：基本情况、主要问题、原因分析、对策建议。每条问题都有对应的建议。

## 内容

- 数据写明口径、时间和来源，例如“2026年9月30日《市统计局公报》”；估算写明所用的假设。
- 问题写具体表现和影响范围，原因写到可以采取措施的层面。
- 建议写清做什么、谁来做、何时完成，能量化的写出目标值。

## 文风

- 少用形容词和副词，用数据和事实说明程度。
