# 叙事小说

## 准备

- 确认篇幅、视角、读者年龄和题材。
- 写下主要人物的目标、阻碍和变化，以及故事的起点和结局。

## 结构

- 开头进入一个具体场景，尽快让人物面对问题。
- 中段让冲突逐步升级，每个场景推动情节或揭示人物。
- 结尾回应开头的问题，人物的变化通过行动表现出来。

## 写法

- 用动作、对话和细节表现人物，让读者自己得出判断。
- 对话符合人物身份，一句对话推动一件事。
- 描写使用具体的感官细节，比喻贴近人物的经验。
- 时间线和人物称呼前后一致。

## 收尾检查

- 运行 style_check（否定式阈值可放宽到 5），对话中的否定句按人物语气保留。
