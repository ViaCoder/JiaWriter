# 营销文案

写产品介绍、活动文案和社交媒体文案：卖点具体，说法可以证明。

## 准备

- 确认产品、目标人群、渠道（公众号、短视频、海报、电商页面）和字数限制。
- 列出产品的具体卖点，每个卖点配一个可以验证的事实或数据。

## 结构

- 标题写出读者能得到的好处。
- 开头一句点出读者的需求或场景。
- 主体按卖点分段，每段写清功能、带来的变化和证据。
- 结尾给出明确的行动指引，例如购买入口、活动时间。

## 文风

- 用读者熟悉的词，描写具体的使用场景。
- 数据、价格、活动规则与官方信息一致，写明有效期。
- 遵守广告法：使用可以证明的表述，比较对象写明出处。
- 按渠道的字数限制用 word_count 核对。
