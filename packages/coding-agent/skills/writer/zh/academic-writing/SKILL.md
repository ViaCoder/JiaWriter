# 学术写作

## 准备

- 确认学科、期刊或学校的格式要求、引文格式（如 GB/T 7714、APA）和篇幅。
- 导入用户提供的文献，按研究问题整理每篇文献的观点、方法和结论，记下页码。

## 结构

- 摘要写清研究问题、方法、主要发现和意义。
- 引言说明研究背景、已有研究的进展和本文要解决的问题。
- 正文按“方法—结果—讨论”或按论点展开，每节开头说明本节任务。
- 结论回答引言提出的问题，并说明研究局限和后续方向。

## 引用

- 每个观点和数据都标注文献来源，引文格式统一。
- 只引用已导入的文献和检索到的公开来源，写明作者、年份和页码。
- 转述时保留原意，直接引语加引号并注明页码。

## 文风

- 用准确的术语，术语第一次出现时给出定义。
- 判断的强度与证据相符，结论写明适用范围。
- 句子结构清楚，主语明确。

## 收尾检查

- 运行 style_check 和 readability_check，导出时可指定学术排版方案。
