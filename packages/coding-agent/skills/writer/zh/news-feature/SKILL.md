# 新闻特稿

## 采集事实

- 用 web_search 搜索事件名称加日期，用 web_fetch 读取权威媒体的原文。
- 每条事实记下来源网址、媒体名称和发布日期。页面上看得到日期的，才写成“最新”。
- 同一事实有两个以上来源时，以权威媒体和官方发布为准，正文写明出处。

## 结构

- 标题概括最重要的事实，用动词，写清主体和动作。
- 导语回答谁、何时、何地、做了什么；第二段补充原因和影响。
- 主体按重要性递减排列，引语放在需要说明立场或情感的地方。
- 综述类稿件按时间或主题分段，每段开头写明时间。

## 文风

- 客观陈述，观点出自消息来源并写明是谁说的。
- 数字、时间、地名、人名、职务与来源保持一致。
- 案例和引语注明日期和来源，例如“据路透社2026年10月31日报道”。

## 收尾检查

- 运行 style_check，再用 word_count 核对篇幅。
