# 通用文章

写说明文、评论、专栏和讲稿：开门见山，一段讲清一件事。

## 结构

- 标题直接点明主题，开头两三句交代要讲的事。
- 主体按“观点—依据—解释”展开，每段讲清一件事，段首句概括本段内容。
- 结尾停在最后一个要点或可以执行的下一步，不做总结。

## 文风

- 直接陈述事情是什么、怎么做，删掉铺垫和套话。
