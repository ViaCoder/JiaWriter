# 通用文章

## 动笔之前

- 先确认主题、读者、用途和篇幅；用户没有说明的，按常见做法定下来，并在回复里说明所作的设定。
- 有参考资料时先用 import_document 导入，再用 grep 查找要用的事实；用户要求检索，或需要资料里没有的最新信息时，用 web_search 和 web_fetch。

## 结构

- 标题直接点明主题。开头两三句交代要讲的事和它的意义。
- 主体按“观点—依据—解释”展开，每段讲清一件事，段首句概括本段内容。
- 结尾归纳要点，给出可以执行的建议或下一步，篇幅与开头相当。

## 文风

- 用常用词和完整的短句，一句话表达一个意思。
- 先摆事实，再下判断；判断写明依据。
- 直接陈述事情是什么、怎么做，删掉铺垫和套话。
- 引用的案例只取自参考资料或检索结果，正文写明日期和来源，例如“2026年10月31日《新华社》报道”，文末“参考文献”列出全部来源的标题和网址。

## 收尾检查

- 完稿后运行 style_check，按提示只改被标出的句子，再运行一次直到通过。
- 用 word_count 核对篇幅，用 readability_check 检查生僻字和过长的句子。
- 用户需要文件时，用 export_document 导出 docx。
