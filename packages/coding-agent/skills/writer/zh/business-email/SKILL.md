# 商务邮件和备忘录

写商务邮件、备忘录和会议纪要：一封信办一件事，对方读完就知道要做什么。

## 结构

- 主题行写清事项和需要对方做的事，例如“请确认：11月5日样品交付安排”。
- 第一段直接说明来意和请求。
- 中间部分按事项分点，写明时间、数量、负责人和截止日期。
- 结尾写清下一步和联系方式，礼貌用语一句即可。

## 文风

- 称呼和语气与收件人的关系相称。
- 用短段落，每段讲一件事。
- 日期写成“2026年11月5日（星期四）”，金额写明币种。
- 发出前核对收件人、日期和数字前后一致。

## 会议纪要

- 写明会议时间、地点、参会人和议题。
- 每项议题记录结论、负责人和完成时间。
