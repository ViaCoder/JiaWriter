# 公文语言

从真实公文 229 篇（91 万字）统计出的用词和句子习惯。需要词汇层细节时读。

## 句子

- 平均句长 45–55 字，近半数句子超过 50 字，长度来自“、”分隔的并列成分；顿号每千字 12–23 个。
- 短句只占一到两成，放在要发力的地方；全篇没有短句会没有起伏。

## 语气

- 默认语气是“要＋动词”（要加强、要确保），占力度词的七到八成。
- “必须”“应当”“不得”“严禁”一篇 3000 字最多三五处，用多了就失效。
- 上行文把“要”换成“建议”，下行文保留“要”；“希望”只用在讲话结尾。

## 常用词

- 动词：推进、加强、开展、落实、完善、提高、形成、实现。
- 副词：进一步、不断、切实、始终、更加；“进一步”一篇最多用三次。
- 形容词：重要、有效、明确、具体、扎实。
- 人称写“我县”“我局”“本机关”，不写“我”“你”。

## 数字

- 统计数据、百分比、年份、文号用阿拉伯数字；成词、概数、序数用汉字（“十八大”“三大攻坚战”“第一书记”）。
- 引用政策写文件全称，很少写文号。
- 数据不是必需品，核实不了的不写，用道理补。
