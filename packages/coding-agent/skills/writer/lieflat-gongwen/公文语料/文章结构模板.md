# 文章结构模板

各文种的一级段顺序、重心和段内写法，从真实公文精读提炼。只读要写的文种那一节。段内分条一律用（一）（二）和段首主旨句，不用“一是”“一要”。

## 调研报告

- 骨架：缘起（1.5–4%，以“现将有关情况报告如下”收尾）→ 做法成效 → 问题原因 → 建议。三段大致等重，没有一段超过 40%；写成一段独大就成了经验材料。
- 汇报型变体：缘起 → 问题表现 → 原因 → 对策（最重，23–39%）；一级标题直接写判断，如“一、四类浪费让人触目惊心”。
- 段内：提领句（背景加判断，并预告下面分几类）→ 分条 → 用案例或数据举证。问题可以用群众的话命名（“前端分类，后端杂烩”），比“体制机制不健全”有信息量。
- 过渡句放在新段段首，不放在上段段尾。

## 领导讲话

- 骨架：称谓、会议目的、议程预告 → 为什么 → 做什么 → 谁来干，固定三个一级段。
- 一级标题前半是动作、后半是目的，约 17 字。
- 段内靠设问、俗语、比喻控制节奏，可以再次称呼“同志们”把听众拉回现场；结尾号召加表态。

## 工作意见

- 骨架：依据目的（“按照……根据……结合……制定本意见”）→ 总体要求（指导思想、基本原则、目标要求）→ 重点任务（44–53%）→ 保障措施。
- 任务多时可把重点任务拆成 5–9 个并列一级段，首尾保留总体要求和组织领导。
- 段内：（一）四字动宾短语加句号 → 一句判断说明为什么要做 → “要……”句群写具体动作。段间不写过渡句。

## 工作方案

- 骨架：依据目的 → 意义或总体要求 → 重点任务（过半）→ 实施步骤 → 组织保障；活动类改为背景 → 宗旨 → 时间地点人员 → 活动形式 → 宣传。
- 段内：（一）动宾短语加句号 → 一句总体路径 → 按年份或阶段写进度，年份就是落点。段间不写过渡句。

## 经验材料

- 骨架：背景 → 做法（47–59%）→ 启示。启示把个案写成别人能用的规律（“对话磋商是解决贸易争端的有效途径”），这是和调研报告的区别。
- 段内：提领句先交出下文的分类轴（“从案前预警、案中应对和案后执行入手”），下面的二级标题按这个轴展开。
- 用成效句收住上一段，下一段直接开始，不写连接词；不写本单位尚未解决的问题。

## 经验总结

- 骨架：总体成效 → 环节一 → 环节二 → 环节三，三段大致等分，没有问题段和启示段。
- 一级标题是“动词＋带引号的数字短语，确保……”的双分句；段首用同一句式（“坚持把……”）起头。
- 每项做法用绝对数收尾（示范岗 3 个、资金 60 余万元），不用百分比。

## 通用规律

- 方案、意见、经验材料把重量压在“做什么”；调研报告、讲话、经验总结各段大致等重。
- 越是规范性文件越不需要过渡句，越要说服人的文体过渡越明显。
